# 치이카와 배구 GBA v0.5.7

**[전체 ZIP·ROM 다운로드](https://github.com/haveanair/chiikawa-volleyball/releases/tag/gba-v0.5.7) · [웹판 플레이](https://haveanair.github.io/chiikawa-volleyball/) · [전체 플랫폼 안내](../README.md)**

릴리스 Assets의 `.gba` 파일 또는 전체 ZIP을 받으세요. `chiikawa-volleyball-v0.5.7-locked.gba`는 도전과제 해금판, `chiikawa-volleyball-v0.5.7-unlocked.gba`는 전체 해금판입니다. 파일명별로 저장 기록이 분리되는 실행 환경에서는 각각 별도 세이브가 생성됩니다.

전체 해금판과 도전과제 잠금판 두 ROM을 포함합니다. 이전 v0.5.6 ROM과 패키지는 보존했습니다.

- Switch와 같은 원근 계산으로 5개 경기 코트와 코트 선택 미리보기를 다시 만들었습니다. 바닥의 중심 축, 네트 기둥과 망의 각도를 함께 맞췄으며 게임 물리 좌표는 바꾸지 않았습니다.
- 처음 실행할 때 ‘작은 친구들의’가 왼쪽에서, ‘큰 승부!!’가 오른쪽에서 들어와 만나고, 두 번의 타격음 후 로고가 위에서 내려옵니다. 이후 기존 타이틀로 이어집니다. 영어 문구와 영어 로고도 준비했습니다.
- 타이틀 복귀와 데모 종료 때 오프닝을 다시 재생합니다. A/B/START로 건너뛸 수 있으며 건너뛰기는 타이틀로만 이동합니다.
- 타이틀 L/R로 한국어/영어를 전환합니다. 제작자 표기는 한국어 2026 파워덕질, 영어 2026 PowerOtaking입니다. 엔딩의 별도 그림 글꼴과 타이틀 라벨을 모두 수정했습니다.
- 하단 온라인 대전 문구는 없습니다. 실제 GBA 두 대와 케이블을 사용하는 로컬 통신 기능 안내는 유지했습니다.


기존 게임 조작: 좌우 이동, 위 점프, A 공격, 위+A 상단 스파이크, START 일시정지. 난이도는 스토리와 CPU 대전에서 각각 L/R로 바꿉니다. 캐릭터 선택 L/R은 승리 점수 설정입니다. SELECT는 진동 설정입니다.

## v0.5.7 오프닝 수정

- 좌우 문구가 만난 직후 나타나던 한 픽셀 점 효과를 제거했습니다. 문구 흔들림과 두 번의 타격음은 유지합니다.
- 첫 화면의 그림과 스프라이트 준비가 끝난 뒤 화면을 표시하도록 초기화를 보강했습니다.
- 양 언어의 오프닝 연속 프레임을 예상 비트맵과 비교하고, 타이틀·데모 복귀와 건너뛰기를 다시 검사했습니다.
