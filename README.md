# 치이카와 배구 / Chiikawa Volley

비영리 2차 창작 팬게임. 제작 파워덕질 2026.

플레이: https://haveanair.github.io/chiikawa-volleyball/

스토리, 로컬 2인 대전, 숫자 4자리 방 번호를 이용한 온라인 친구 대전을 지원합니다. 방장이 방 번호를 알려주고 친구가 참가한 뒤 대전을 시작하세요.

스마트폰은 가로 화면에서 왼쪽 방향 버튼(좌·우·점프)과 오른쪽 공격 버튼으로 조작합니다. 점프와 공격을 함께 누르면 상단 스파이크가 나갑니다.

현재 테스트판은 모든 캐릭터가 개방되어 있습니다.

웹 배포 파일은 docs/, GBA 이식을 고려한 C 경기 코어는 shared/, 방 관리 서버 소스는 server/supabase/에 있습니다. 온라인 통신은 기존 Supabase 프로젝트의 배구 전용 기능을 사용합니다.

캐릭터 원작: 나가노 / 치이카와. 게임 기반: 하모 아요 배구 GBA, 피카츄배구, 치이카와 포켓. 캐릭터·이미지·음원의 권리는 각 권리자에게 있습니다. 하모 아요 코드의 MIT 고지는 docs/LICENSE-HAMO-MIT.txt를 참고하세요.
