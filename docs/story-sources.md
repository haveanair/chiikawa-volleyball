# 경기 전 대화의 원작 참고 자료

경기 전 장면은 원작의 관계·말투를 참고한 **게임용 각색**입니다. 사용자가 2026-10-19에 각색 범위를 승인했습니다. 화면에도 게임용 각색이라고 표시합니다. 선택한 주인공과 해당 스테이지 상대가 배경 위에 등장해 네 차례 말·외침·몸짓을 교환하며, 마지막에는 준비 연출 후 실제 경기를 시작합니다. 14개 주인공 × 5개 상대 조합을 지원합니다.
