# 치이카와 배구 Switch v0.7.9

**[NSP·NRO·전체 ZIP 다운로드](https://github.com/haveanair/chiikawa-volleyball/releases/tag/switch-v0.7.9)**

## 두 가지 NSP

| 파일 | 설치되는 한국어 이름 | 캐릭터 | 타이틀 ID |
|---|---|---|---|
| 치이카와_배구_Switch_v0.7.9.nsp | 치이카와 배구 | 치이카와·하치와레·우사기로 시작, 도전과제로 해금 | 0100C11A4A002000 |
| 치이카와_배구_Switch_v0.7.9_해금버전.nsp | 치이카와 배구 · 해금버전 | 14개 선택 슬롯 전체 개방 | 0100C11A4A000000 |

기본판에는 ‘잠금버전’이라는 명칭을 붙이지 않았습니다. 기본판은 복숭아색, 해금판은 민트색 아이콘 배경으로 구분하며, 두 아이콘 모두 중앙 하단에 게임 로고가 있습니다. 서로 다른 타이틀 ID라 함께 설치할 수 있습니다. 기존 v0.7.5의 전체 해금판은 같은 ID의 해금버전으로 업데이트됩니다.

해금판은 기존 /switch/chiikawa-volley-progress.json을 유지합니다. 기본판은 /switch/chiikawa-volley-progress-locked.json을 사용해 기록과 백업을 분리합니다. 기존 기록을 지우지 않습니다.

## 변경 및 확인

- 스토리와 CPU 대전 난이도를 독립적으로 선택합니다. 스토리의 쉬움·보통·어려움과 CPU 대전 설정이 서로 덮어써지지 않습니다. Switch 난이도 순환은 1/3/5입니다.
- 한국어 타이틀과 엔딩의 제작자는 2026 파워덕질, 영어는 2026 PowerOtaking으로 표시합니다. 설치 정보도 한국어 슬롯과 나머지 언어 슬롯을 구분했습니다.
- 현재 온라인 대전은 실제 서버 연결과 동기화가 구현돼 있지 않으므로 캐릭터 선택 메뉴와 타이틀 하단의 온라인 안내를 제외했습니다. 런타임의 통신 API가 없는 것은 아니며, 향후 온라인 이식 가능성과 현재 기능 제공 여부는 별개입니다.
- 웹·GBA·Switch가 같은 코트 원근 계산을 사용합니다. 게임 물리 좌표는 유지합니다.
- 이전 시작 음성 순환, 다음 서브 이름, 쿠리만쥬 표정, 세이렌 크기, 엔딩 글꼴·메모리 수정도 포함합니다.

잠금 조건은 스토리 승리 차, 공격 및 초필살기 누적, 엔딩 달성 등 기존 웹·GBA 도전과제와 같습니다. 패드 확정·동시 2인 확정·터치 확정에서 조건을 검사합니다. CPU 적 캐릭터도 선택할 때 같은 조건을 적용합니다.

NRO 폴더는 전체 해금판입니다. NSP 두 종류와 별도로 홈브류 실행이 필요한 경우 사용합니다.
